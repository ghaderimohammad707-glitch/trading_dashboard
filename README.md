# نبض بازار (Nabz-e Bazar)

پلتفرم تحلیل حرفه‌ای بازار سرمایه ایران — داده‌های واقعی، بدون اطلاعات ساختگی

## 🚀 وضعیت پروژه

**نسخه فعلی:** 1.0.0-alpha  
**وضعیت:** در حال توسعه فعال  
**تمرکز:** داده‌های واقعی و شفافیت کامل

## ✨ ویژگی‌های کلیدی

### ✅ ماژول‌های فعال
- **دیده‌بان بازار:** نمایش لحظه‌ای نمادهای بورس و فرابورس با فیلترهای پیشرفته
- **تابلوخوانی:** تحلیل عمق بازار، ورود/خروج پول حقیقی و حقوقی
- **سیگنال ترکیبی:** امتیازدهی چندلایه (تکنیکال، تابلو، حجمی، بنیادی)
- **پرتفو:** مدیریت دارایی‌ها با امکان ایمپورت اکسل
- **بک‌تست:** تست استراتژی‌های معاملاتی
- **کارت‌های ویوی زنده:** شاخص‌ها، ارز، طلا، سکه، کریپتو
- **اخبار:** موتور تحلیل خبری با منابع ایرانی و بین‌المللی
- **هشدارها:** سیستم هشدار قیمت با ذخیره‌سازی پایدار

### ⚠️ محدودیت‌ها
- **کدال:** فعلاً به دلیل محدودیت CORS نیاز به پروکسی سرور دارد
- **احراز هویت:** نسخه فعلی بدون احراز هویت واقعی کار می‌کند (در حال توسعه)
- **Order Flow:** فقط از داده‌های واقعی استفاده می‌شود (شبیه‌سازی حذف شده)

## 🛠 تکنولوژی‌ها

- **Frontend:** React 19 + Vite + TypeScript
- **Styling:** Tailwind CSS 4 + shadcn/ui
- **Routing:** React Router 7
- **Database:** IndexedDB (ذخیره‌سازی محلی) + PostgreSQL (آماده اتصال برای بک‌اند)
- **Charts:** Lightweight Charts + Recharts
- **State Management:** React Hooks + Context API

## 📦 نصب و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# بیلد پروداکشن
npm run build
```

## 🔧 پیکربندی

### متغیرهای محیطی (اختیاری)
فایل `.env` را در ریشه پروژه ایجاد کنید:

```env
# Database (optional - برای نسخه بک‌اند)
DATABASE_URL=postgresql://user:password@localhost:5432/nabz_bazar

# Telegram Bot Token (برای ارسال هشدار - اختیاری)
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

|------|--------|-------|
