# فونت‌های فارسی برای گزارش‌های PDF

## راهنمای نصب

برای پشتیبانی کامل از زبان فارسی در گزارش‌های PDF، باید فونت‌های زیر را در این پوشه قرار دهید:

### فونت‌های پیشنهادی:
1. **BNazanin.ttf** - فونت اصلی متن فارسی
2. **BNazaninBold.ttf** - نسخه ضخیم برای تیترها
3. **BMitra.ttf** - فونت جایگزین

### روش‌های تهیه فونت:

#### روش ۱: دانلود از منابع آزاد
- فونت‌های سری B (نازنین، میترا، تیتر) به صورت رایگان از سایت‌های فارسی موجود هستند

#### روش ۲: استفاده از فونت‌های سیستم
```bash
# در لینوکس
sudo apt-get install fonts-farsiweb

# در مک
# فونت‌های فارسی معمولاً نصب هستند
```

#### روش ۳: کپی از ویندوز
فونت‌ها را از `C:\Windows\Fonts` کپی کنید

## ساختار پوشه
```
src/assets/fonts/
├── BNazanin.ttf          # فونت اصلی
├── BNazaninBold.ttf      # فونت ضخیم
└── README.md             # این فایل
```

## نکات مهم
- بدون فونت فارسی، متن‌ها به صورت جدا جدا نمایش داده می‌شوند
- pdfkit از فونت‌های TrueType (.ttf) پشتیبانی می‌کند
- حجم هر فونت حدود ۵۰-۲۰۰ کیلوبایت است
